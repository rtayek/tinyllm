# What Structure Is This Model Learning?

This note treats `tinyllm` as an experiment in representation learning rather
than primarily as a text-generation project.

## Status of Measurements

The measurements below were taken against a checkpoint at step 3100 trained on
the **legacy Sherlock corpus** (a raw 90/10 byte-position split of the Project
Gutenberg file, including license boilerplate in the validation region). That
corpus and checkpoint have since been replaced.

The **current default checkpoint** is at step 4500, trained on the canonical
8-story / 2-story / 2-story split generated by `tinyllm-prepare-corpora`. All
measurements below need to be reproduced against this checkpoint before they
can be treated as current. See the Research Plan section for how to do this.

---

## Current Answer (from legacy checkpoint)

The checkpoint had clearly learned:

- byte classes such as punctuation and digits,
- spelling and common character transitions,
- word shapes and frequent short phrases,
- some useful context beyond the current word,
- broad late-layer attention patterns.

It had not demonstrated strong evidence of:

- robust syntax,
- discourse or story-state tracking,
- semantic representations that generalize beyond the corpus,
- substantial passage memorization,
- a predictive advantage over a well-tuned local n-gram model.

The most important result: a smoothed 4-gram model reached validation loss
`2.0065` nats per byte, while the transformer reached about `2.03`. Most
predictive performance at that checkpoint was explainable by the previous
three bytes. The 4-gram baseline must be reproduced on the canonical split
before any new experiment can claim to exceed it.

## Evidence (legacy checkpoint, step 3100)

### Baselines

| Model | Validation loss | Perplexity |
| --- | ---: | ---: |
| Unigram | 3.2530 | 25.87 |
| Bigram | 2.5669 | 13.03 |
| Trigram | 2.1477 | 8.57 |
| 4-gram | 2.0065 | 7.44 |
| 5-gram | 2.2697 | 9.68 |
| Transformer | ~2.03 | ~7.6 |

The 4-gram result should remain a mandatory baseline for future experiments.
Higher-order n-grams are sparse on this small corpus.

### Effective Context

Predicting the next byte from progressively longer suffixes:

| Context bytes | Loss |
| ---: | ---: |
| 1 | 2.6726 |
| 2 | 2.2430 |
| 4 | 2.0555 |
| 8 | 2.0141 |
| 16 | 2.0115 |
| 32 | 2.0166 |
| 64 | 2.0074 |
| 128 | 2.0406 |

This comparison changes absolute position as context length changes, so it is
not a clean test. A controlled test kept the input at 128 positions and
replaced the distant prefix with a natural prefix from another validation
location:

| Correct suffix retained | Loss |
| ---: | ---: |
| 1 | 3.4214 |
| 2 | 2.5224 |
| 4 | 2.2065 |
| 8 | 2.1504 |
| 16 | 2.1253 |
| 32 | 2.1223 |
| 64 | 2.0578 |
| 128 | 2.0619 |

The first four bytes provide most of the gain. Context from 4 to 64 bytes is
still useful (~0.15 nats), but the final 64 bytes add no measurable benefit in
this sample.

### Destroying Different Structures

| Input structure | Loss | Change |
| --- | ---: | ---: |
| Natural text | 2.0278 | — |
| Words shuffled | 2.2709 | +0.2431 |
| Letters shuffled within words | 4.1910 | +2.1632 |
| All bytes shuffled | 4.9638 | +2.9360 |
| Text reversed | 4.2628 | +2.2350 |

Destroying spelling is far more damaging than destroying word order. This is
the clearest evidence that the model represents orthographic and local phrase
structure much more strongly than syntax.

### Layer Contributions

| Intervention | Loss |
| --- | ---: |
| No intervention | 2.0046 |
| Remove layer 0 attention | 2.5775 |
| Remove layer 1 attention | 2.0335 |
| Remove layer 2 attention | 2.0220 |
| Remove layer 3 attention | 2.0245 |
| Remove layer 0 MLP | 4.1773 |
| Remove layer 1 MLP | 2.0914 |
| Remove layer 2 MLP | 2.0608 |
| Remove layer 3 MLP | 2.0358 |

Removing all attention raises loss to ~2.85; removing all MLPs raises it to
~3.98. Removing blocks 1–3 together raises loss to ~2.60, even though each
later component has a small individual effect. The first block is dominant;
later blocks provide distributed or partly redundant refinements.

Zeroing positional embeddings raises loss from ~2.04 to ~2.73. Position
information is causally important, but this does not prove linguistic position
is learned — it may partly reflect reliance on the training architecture's
absolute-position convention.

### Attention Patterns

First-layer heads attend locally, with expected look-back distances around
8–16 bytes and 18–35% average weight on the immediately previous byte. The
last layer is much broader, with expected distances around 34–43 bytes and
high attention entropy.

This resembles a local-to-broad progression, but broad attention is not
automatically meaningful attention. The late heads are diffuse, and individual
late attention ablations barely change loss. Attention weights should be
treated as hypotheses for causal tests, not as explanations.

### Embeddings

Nearest-neighbor structure appears for several byte classes:

- `.` is close to `?`, `!`, `;`, `,`, and `:`.
- `0` is close to other digits.
- lowercase `a` is close to uppercase `A` and other vowels.
- space is related to newline and formatting characters.

Unused or rare byte values also appear among neighbors because many of the 256
possible bytes are poorly trained. Distinguish frequent ASCII bytes from rare
UTF-8 continuation bytes and unused values in any analysis.

### Memorization

With an 80-byte prompt and greedy generation, exact continuation matches were
short:

| Split | Mean exact prefix | Maximum |
| --- | ---: | ---: |
| Train | 1.00 byte | 7 bytes |
| Validation | 0.45 byte | 4 bytes |

This does not support substantial verbatim passage memorization, but does not
rule out distributed memorization of names, phrases, or corpus statistics.

## Historical Dataset Confounds

The legacy split was a contiguous 90/10 split of one Project Gutenberg file.

- Validation started partway through "The Copper Beeches".
- The story ended at ~96.9% of the file.
- ~31% of the validation region was Project Gutenberg license text and website
  boilerplate, not Sherlock Holmes prose.
- Adjacent train and validation regions shared author, characters, formatting,
  and document-level artifacts.

The current canonical split addresses all of these: the corpus pipeline strips
Gutenberg wrappers, splits at story boundaries, and assigns complete stories
to train (8), validation (2), and test (2). This is a clean held-out design.

## Recommended Research Plan

### 0. Reproduce Baselines on the Canonical Split (First Priority)

Before running new experiments, establish a current baseline:

1. Run n-gram models (unigram through 5-gram) on the canonical validation split.
2. Record the current transformer validation loss at step 4500.
3. Run the context-restriction probe (replace distant prefix) on the current
   checkpoint.
4. Run the structure-destruction probe (shuffle words, shuffle letters, reverse).

This reproduces the measurements above on the clean corpus and updates the
reference point for all future work.

### 1. Preserve Training Trajectories

For structure analysis, save model snapshots at intervals that capture early
learning, for example:

```text
0, 50, 100, 200, 400, 800, 1600, 3200, 4500
```

Run the same probes on every snapshot. The interesting question is not only
what exists at the end, but when spelling, word boundaries, induction, and
longer context become useful.

### 2. Scale Data and Model

Before fine-grained probing experiments, the highest-leverage changes are:

- Add more training corpora (more Project Gutenberg texts).
- Scale model capacity: more layers, wider embeddings, longer blockSize.

A larger model on more data may cross the threshold where the transformer
clearly beats the 4-gram baseline, making later probing experiments more
informative.

### 3. Add Instrumentation

Add an analysis-only forward path that can return:

- residual stream after each block,
- attention matrices per layer and head,
- MLP activations,
- logits after each intermediate layer.

Keep the normal training API unchanged. Instrumentation should be optional so
it does not retain large tensors during ordinary training.

### 4. Use Causal Tests

Prefer interventions over visual inspection:

- patch one head's output from a clean example into a corrupted example,
- zero or replace selected attention edges,
- swap residual states between minimal-pair prompts,
- restrict attention to the last `k` bytes,
- compare original and corrupted contexts with positions held fixed.

A linear probe can show that information is present. A causal intervention is
needed to show that the model uses it.

### 5. Build Controlled Synthetic Corpora

Natural prose contains too many correlated features. Train small models on
datasets where the required structure is known:

- balanced brackets with varied nesting depth,
- subject-verb agreement across distractors,
- repeated-token induction such as `A B ... A → B`,
- copy and reverse tasks,
- quotation or delimiter closure,
- latent word classes generated by a small grammar,
- names assigned temporary properties that must be recalled later.

Vary one factor at a time: context length, number of layers, number of heads,
data volume, and tokenizer.

### 6. Compare Against Restricted Models

Every experiment should include:

- unigram through n-gram baselines,
- a model restricted to the last 4 or 8 bytes,
- an attention-free baseline,
- a one-layer transformer,
- the full transformer.

Claim longer-range learning only when the full model beats both the n-gram and
restricted-context controls on held-out structures.

### 7. Keep Byte Tokens for Research; Add BPE as a Comparison

Byte tokens are an advantage for representation research. They force the model
to construct letters, word boundaries, spelling, and larger units from raw
symbols. A BPE tokenizer would improve generation efficiency but would build
some of that structure into preprocessing, obscuring what the transformer has
learned.

Add BPE only as a controlled comparison after scaling:

- train byte and BPE models on the same text,
- approximately match parameter count and training compute,
- compare when each representation acquires syntax and long-range behavior.
